# Cross-repository conformance

`snapshot-analyzer.json` binds the temporary bridge's exact teacher request contract to the committed `milk-carton` source revision and `records.rs` hash. The native release builder checks the frozen Carton commit, whole-file hash, system prompt, and response schema before building the bridge images. Later contract changes require coordinated commits; the jobs runtime image binds the admitted Carton contract digest.

Harness evidence JSON is UTF-8 with sorted keys, compact separators, and one
trailing LF. A version SHA-256 covers those exact bytes. An unsigned route
proposal uses `milk.unsigned-route-proposal.v2` and names `profile`, `series_id`,
`code_version`, source, summary, readiness, eval, validation, and candidate-score
digests. Carton must re-read and hash-verify each named object, require an
accepted `milk.eval-validation-revision.v1`, require a qualified
`milk.candidate-score-revision.v1`, and verify every adjacent digest link before
preparing a signable manifest. Neither object authorizes activation.
